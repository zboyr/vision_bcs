# Cat BCS 10K Dataset

10,000 YOLO-cropped cat images with Body Condition Score (BCS) annotations
generated by Gemini 3.1 Pro.

## Structure

```
cat_bcs_10k/
├── images/          # 10,000 YOLO-cropped cat images (md5.jpg)
├── cat_db.json      # TinyDB records: md5, source, YOLO conf, ViTPose pose info
├── bcs_scores.csv   # Gemini 3.1 Pro BCS scores (1-9), breed, confidence
├── dataset.csv      # id → path → md5 mapping
└── rejected_md5.txt # MD5 list of images rejected during filtering
```

## Pipeline

1. **Download**: COCO 2017 + 3 HuggingFace cat datasets (~29k raw images)
2. **YOLO filter**: yolo11m detects cat, crops to strict bbox
3. **ViTPose verify**: AP-10K animal pose estimation requires body + ≥3 visible limbs + kpt spread ≥30%
4. **Score**: Gemini 3.1 Pro → JSON (BCS primary/secondary, breed, confidence, reasoning)
